# WorkSpotMap — 空席マップ MVP (SwiftUI / MapKit)

## 起動方法
1. Macで `WorkSpotMap.xcodeproj` をXcode 16以降で開く。
2. iOS 17以上のiPhoneシミュレータを選ぶ。
3. ▶ Run を押す。シミュレータで試す限り開発者アカウントは不要。
4. 駅名・地名（例：早稲田駅、梅田駅、新宿駅）を入力し「検索」。Apple MapKitの検索で地図を移動。
5. ピンをタップすると施設詳細を確認。下部の「施設用デモ」タブで混雑を変更し、地図に反映されることを確認。

## MVPに入っていること
- 新宿・早稲田周辺の架空の施設50件でピン密度を確認
- 正方形の地図と、その下の仮広告1枠
- スポンサーカフェ1件を名前付きの大きなPRピンで表示（通常ピンは名前なし）
- 駅名・地名検索 (MKLocalSearch)、地図移動
- カフェ / 図書館 / 自習室 / コワーキングのピンとカテゴリ絞り込み
- 緑 / 黄 / 赤 / 灰の混雑表示
- 施設の概要・Wi-Fi / 電源表示
- 施設側3ボタン更新（空・やや混雑・満席）、不明へ戻す操作
- 同一端末での状態共有・ローカル保存
- 将来の利用者投稿を想定した `CrowdReport` データ構造

## 今回は入れていないこと
- GPS / 現在地の取得・自動追跡
- 混雑情報の「古い」表示や自動期限切れ
- 利用者による混雑投稿（将来対応）
- 施設管理者ログイン・施設認証・サーバーとのリアルタイム共有
- 店舗登録・実際の広告配信や決済

**ご注意**: ピンはすべて架空のサンプル施設です。実店舗の空席は表示していません。地域検索は実際のApple Mapsの地名・駅名検索ですが、対応するサンプル施設がない地域ではピンが出ません。ネット接続が必要です。

## 本番運用へ向けて
施設情報DB、管理者認証、混雑更新API、Firestore等への同期、管理権限の確認、利用者投稿の信頼性対策が必要です。将来の利用者投稿は施設公式の混雑更新を上書きせず、別ソースとして扱う設計が望ましいです。
